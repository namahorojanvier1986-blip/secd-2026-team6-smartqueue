# M2 - Requirements

This folder contains the Software Requirements Specification (SRS) for Team 6 project.

## Files in this folder

- T6-M2-SRS.pdf - Full M2 document (Functional Requirements, Non-Functional Requirements, MoSCoW Prioritisation)

## Summary

This SRS defines what the system must do, based on evidence from M1 Discovery (E1-E6).

Functional Requirements cover the core features for customers and tellers. Non-Functional Requirements cover security, performance, and accessibility.

Prioritisation uses MoSCoW: Must Have, Should Have, Could Have, Won't Have.
