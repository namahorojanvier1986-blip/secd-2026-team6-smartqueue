# SQMS Style Guide - Umwalimu SACCO

## Colors
- Primary Blue: #0b5cad - Buttons, Titles
- White: #ffffff - Background
- Black: #1a1a1a - Text
- Yellow: #ffc107 - Priority badge
- Red: #b00020 - Error

## Typography
- Font: Arial, sans-serif
- Title: 24px, Bold, Blue
- Body: 16px minimum - for elderly teachers
- Ticket Number: 32px, Bold

## Buttons
- Height: 48px minimum - easy to tap on phone
- Width: 100% on phone
- Radius: 8px

## Accessibility
- Language: EN | RW toggle
- Priority: Elderly, Pregnant, Disability
- High contrast, no small text
